같은 몸에 얼굴 A/B/C만 다르고 목소리도 다 변조된 5명의 후보 속에서, 정보가 하나도 없는 판정단 한 명이 "진짜"를 찾아내는 3D 파티 게임.

승리 조건이 일반적인 숨바꼭질류와 반대인 것이 핵심 차별점이다. 후보(진짜·모방자 모두)는 "안 들키기"가 아니라 "최종 결정에서 판정단에게 지목받기"가 목표다. 모방자가 지목되면 그 모방자의 승리이자 판정단의 실패이고, 진짜가 지목되면 진짜와 판정단 모두의 승리다.
인원 스케일링
인원수는 로비에서 자유롭게 늘렸다 줄였다 할 수 있다. 진짜와 판정단은 인원수와 무관하게 항상 각 1명이고, 늘어나는 인원은 전부 모방자로 배정된다(모방자 = 총 인원 − 2). 다만 인원이 늘어날수록 자기소개·질문 타임 소요 시간이 후보 수에 비례해 늘어나고, 중간 평가가 1회만으로는 후보를 충분히 좁히지 못하므로 아래처럼 인원 구간별로 중간 평가 횟수를 늘리는 것을 권장한다.

3. 위장 시스템
외형: 전원 동일 스켈레탈 메시 사용, 얼굴만 A/B/C 세 종류 중 라운드마다 랜덤 배정.
음성: 라운드마다 랜덤 필터(고음/저음/로봇톤 등) 적용, 원래 목소리 노출 차단.
로비 외형 커스터마이징: 역할이 정해지기 전, 전원이 로비에서 색상·의상·액세서리 등을 자유롭게 꾸민다(스켈레탈 메시는 공용 유지). 아직 누가 진짜인지 모르는 시점이라 전략적으로 유리하게 꾸밀 수가 없다 — 순수하게 '내가 원하는 모습'을 고르는 시간.
역할 배정 시 위장 복제: 역할이 확정되는 순간 서버가 '진짜'의 로비 커스터마이징 데이터를 스냅샷으로 캡처해 모든 모방자에게 그대로 복제 적용한다 — 후보 전원이 겉모습까지 완전히 동일해진 상태로 라운드를 시작한다.
모방자 재조정(모창 준비) 시간: 복제 직후 모방자에게 짧은 준비 시간이 주어져, 복제된 모습을 기준으로 세부 디테일을 자유롭게 다시 매만질 수 있다. 단 '진짜'의 모습은 스냅샷 시점에 고정되어 이후 바뀌지 않는다 — 다른 후보들이 따라가야 할 기준점이 흔들리면 안 되기 때문.
탈락 시 위장 해제: 중간 평가에서 탈락한 후보는 얼굴·목소리 위장은 물론 복제된 외형도 모두 풀리고, 자신이 로비에서 원래 선택했던 커스터마이징 모습으로 돌아간다 — '클론'을 벗고 '진짜 나'로 돌아가는 연출.
정보 비대칭 유지: 이 커스터마이징·복제 과정이 진행되는 동안 판정단에게도 동일한 길이의 화면(자신의 게임과 무관한 외형을 만지는 더미 편집 화면)을 띄워, 화면 전환 타이밍만으로 '지금이 역할 배정 직후구나' 하는 정보가 새지 않도록 한다.
4. 감정표현(이모트) 시스템
음성·텍스트만으로는 즉각적인 리액션을 표현하기 어렵고, 특히 유령 상태(음성 차단)에서는 최소한의 의사표현 수단이 필요하다. 1차 구현 범위는 손동작만 이용하는 4종으로 확정한다.
확정 4종: 뻐큐, 따봉(긍정/찬성), 따봉 내리기(부정/의심), 브이.
입력: 라디얼 메뉴(홀드) 또는 단축키 1~4번. 파티 게임 특성상 즉발성이 중요해 딜레이 없는 짧은 애니메이션 블렌드로 처리.
모든 페이즈에서 상시 사용 가능. 유령 상태에서도 음성만 막히고 이모트는 계속 쓸 수 있어, 관전자도 최소한의 리액션은 표현할 수 있다.
연출 시너지: 따봉/따봉 내리기가 사실상 무언의 찬반 신호라, 질문 타임 토론이나 중간 평가·최종 결정 직전에 이 제스처가 자연스럽게 여론(누가 의심스러운지)을 드러내는 역할을 겸한다.

전원 재집결 지점

페이즈가 전환될 때마다 플레이어를 해당 구역으로 자동 이동시킨다. 로딩 부담을 줄이기 위해 이동 연출은 페이드아웃 후 텔레포트 방식을 권장한다. 질문 존과 자유시간 존은 서로 다른 공간으로 분리하고, 1대1 면담 존은 별도 레벨을 만들지 않고 자유시간 존과 같은 레벨 안에 배치해 텔레포트만으로 오가도록 구현한다 — 로딩 비용 없이 격리감을 낼 수 있는 가장 가벼운 방법이다.
자유시간 존 상호작용 소품
정보 단서용 소품은 넣지 않는다. 대신 자유 시간을 시각적으로 활기차게 만들고 리액션을 유발하는 소음/코미디 소품을 배치한다.
확성기: 들고 사용하면 목소리가 맵 전체(혹은 넓은 반경)에 크게 울려퍼짐.
배트: 근처 소품이나 다른 플레이어를 가볍게 쳐서 코믹한 리액션(넉백/비명 효과음)을 유발.
종/핸드벨: 흔들면 맑고 큰 종소리가 남 — 순간적으로 시선을 모으는 용도.
에어혼(에어 나팔): 크고 우스꽝스러운 경적 소리, 짧고 강렬한 리액션용.
드럼/북: 두드릴 때마다 소리가 나고, 여러 명이 동시에 두드리면 소음이 중첩되는 연출 가능.
호루라기: 짧고 날카로운 신호음 — 긴급하게 시선을 끌 때.
폭죽/컨페티 캐논: 터뜨리면 소리와 함께 화려한 시각 효과, 라운드 분위기를 환기하는 용도.
라디오/스피커: 켜면 배경음악이나 효과음이 재생돼 주변 분위기를 바꿈.
디자인 포인트: 소품을 쓰면 클수록 시선이 쏠린다는 트레이드오프를 자연스럽게 넣으면 좋다 — 확성기로 크게 떠들면 재밌지만 그만큼 판정단의 주목을 끌게 되는 식으로, 순수 코미디 소품이 약한 전략적 리스크도 겸하게 된다.

한 라운드는 약 10분 50초로 확정했다(6인 기본 구성 기준). 스낵 게임보다는 한 판에 확실히 몰입하는 파티 게임에 가까운 길이로, 한 세션에 3~4판 돌리면 40분 안팎이 된다. 판정단 1명이 후보 5명을 상대해야 하는 비율이라, 공개 정보를 값싸게 모으는 페이즈(자기소개·질문 타임)를 먼저 배치하고 그 직후에 1차 압축(중간 평가)을 넣어, 시간이 오래 걸리는 1:1 자유시간·면담을 좁혀진 후보에게만 투자하도록 설계했다.
질문 타임 세부 흐름 (텍스트 Q&A + 상시 음성)
질문 작성(20초): 누구나 자유롭게 질문을 타이핑해서 제출. 음성 채널은 계속 열려있어 "뭐 물어볼까" 잡담이 자연스럽게 오간다.
답변 작성(15초): 후보 전원이 동시에 답변을 타이핑. 다른 사람 답변은 전원 제출(또는 타이머 종료) 전까지 숨김 처리해 커닝을 방지한다.
답변 공개 & 토론(30초): 답변이 전원에게 동시에 공개되고, 음성으로 짧게 반응·논쟁하는 시간이 이어진다.
이 사이클을 라운드당 2회 반복. 설정에서 1~3회로 조정 가능하게 열어둔다.
1대1 면담 대상 지정
면담 대상은 자유 시간 2차 도중 판정단이 지정한다 — 잠정 선택이라 자유시간이 끝나기 전까지 몇 번이든 바꿀 수 있다.
공개형으로 진행: 지정되는 즉시 해당 후보에게 표시가 뜨고 다른 플레이어도 볼 수 있다. "나 찍혔다…" 하는 리액션이 자유시간 후반부의 콘텐츠가 된다.
자유시간 종료 시점까지 아무도 지정하지 않았다면 랜덤으로 한 명이 배정된다.
이렇게 지정을 미리 끝내두는 덕분에 1대1 면담(30초)은 선택 없이 곧바로 심문에 들어간다.
탈락자(유령) 처리
중간 평가에서 지목된 후보는 즉시 게임 경쟁에서 제외되고 "유령" 상태가 된다.
위장(얼굴·목소리)이 해제되어 본모습으로 돌아가며, 맵을 자유롭게 돌아다니며 관전할 수 있다.
단, 음성 소통은 불가 — 남은 후보나 판정단에게 힌트를 흘려 공정성을 해치는 것을 방지.
7. 설계 원칙
규칙은 한 문장, 이해는 1초 이내 — 룰 설명 부담을 최소화한다.
정보 비대칭이 곧 서스펜스다 — 모방자는 알고 판정단은 모르는 구조를 유지해야 진짜 추리의 긴장감이 산다. 판정단도 아는 상태로 가면 미스터리가 아닌 취향 투표(오디션쇼)로 성격이 바뀐다.
탈락은 처벌이 아니라 전환이다 — 유령 상태로 관전은 계속하되 발언은 막아 이탈감과 정보 유출을 동시에 해결한다.
점수 체계 없음 — 최종 지목 발표 그 자체가 라운드의 보상이자 클라이맥스.
목소리 변조 + 근접 상호작용은 그 자체로 스트리밍/SNS 클립 소재가 된다(Peak, R.E.P.O., Voicemod 트렌드 참고).
8. 구현 기능 목록
언리얼 엔진 + 스팀 출시를 전제로, 이 기획을 실제로 돌리는 데 필요한 기능을 영역별로 정리했다.
8-1. 네트워킹 / 매칭
가변 인원 로비: 4~12명 범위에서 자유롭게 인원이 늘고 줄 수 있는 세션(슬롯 동적 관리).
Steamworks SDK 연동: 세션 생성·검색·초대, 친구 초대, Rich Presence(친구가 어느 페이즈인지 표시).
리슨 서버 또는 데디케이티드 서버 결정 — 파티 게임 특성상 리슨 서버 + 호스트 마이그레이션이 현실적.
서버 권위적 페이즈 타이머: 8단계 라운드 상태 머신을 서버가 관리해 치팅(타이머 조작 등) 방지.
8-2. 음성 / 텍스트
근접 음성 채팅: 엔진 기본 기능이 아니므로 Vivox 등 미들웨어 연동 필요.
실시간 음성 변조(피치 시프트): 별도 플러그인/오디오 파이프라인 필요 — 현재 설계의 핵심 기술 리스크.
1대1 면담 전용 음성 채널 분리(격리 존 진입 시 해당 두 명만 묶임).
유령 상태 마이크 강제 비활성화 로직.
질문 타임 텍스트 동시 제출·일괄 공개: 전원 제출 또는 타이머 종료 시점까지 서버가 답변을 보류했다가 한 번에 브로드캐스트.
8-3. 캐릭터
공용 스켈레탈 메시 + 얼굴 A/B/C 머티리얼(또는 모프타겟) 스와핑 시스템.
감정표현(이모트) 애니메이션 몽타주 4종(뻐큐/따봉/따봉 내리기/브이) + 라디얼 메뉴/단축키 입력.
기본 3인칭 이동 컨트롤러, 상호작용 프롬프트(대상 지정, 근접 상호작용 등).
로비 외형 커스터마이징 시스템: 색상·의상·액세서리 등 모듈형 파츠를 고르는 UI, 선택 데이터를 플레이어별로 저장.
역할 배정 시 진짜→모방자 외형 스냅샷 복제 로직: 서버가 '진짜'의 커스터마이징 데이터를 캡처해 모방자 캐릭터 전원에 즉시 적용.
모방자 전용 재조정(모창 준비) UI — 복제된 모습을 기준으로 세부 디테일만 다시 편집. '진짜'는 스냅샷 이후 편집 잠금.
판정단용 더미 편집 화면 — 실제 게임에 반영되지 않는 자기 외형 편집 화면으로, 위 복제 과정과 화면 노출 타이밍을 맞춰 정보 유출 방지.
8-4. UI/UX
로비 UI: 인원수·라운드 옵션(질문 타임 사이클 수 등) 조정, 시작 버튼.
역할 배정 리빌 UI: 본인 역할만 비공개로 표시.
자기소개/질문 타임 텍스트 입력 UI + 동시 제출 대기 상태 표시.
중간 평가·최종 결정 지목 UI, 면담 대상 지정 UI(공개형 표시 포함).
유령(관전) 모드 UI — 마이크 비활성 안내, 이동/이모트만 가능함을 표시.
페이즈 전환 안내 UI(현재 페이즈명 + 남은 시간 타이머).
8-5. 게임 로직
인원수에 따른 역할 자동 배정(진짜 1, 판정단 1, 나머지 모방자) 및 중간 평가 횟수 자동 산정.
투표/지목 집계 로직(중간 평가, 최종 결정 공통 모듈로 재사용).
유령 전환 로직: 위장 해제 + 음성 비활성화 + 이동/이모트만 허용.
라운드 반복 시 역할 로테이션(같은 사람이 연속으로 판정단/진짜를 맡지 않도록).
8-6. 맵/레벨
6개 구역(로비/자기소개 존/질문 존/자유시간 존/1대1 면담 존/중간·최종 평가 존) 및 구역 간 텔레포트 이동 로직.
1대1 면담 존은 자유시간 존과 같은 레벨에 배치 — 별도 레벨 로딩 없이 텔레포트로만 진입/복귀.
1대1 면담 존의 시각·청각 격리 처리(다른 플레이어의 카메라·음성이 침투하지 않도록).
자유시간 존 소음/코미디 소품(확성기, 배트 등)의 상호작용 로직 — 사용 시 반경 내 전원에게 사운드 브로드캐스트.
9. 로비 사전 설정 옵션
게임 시작 전 로비에서 조정 가능한 옵션을 정리했다. 대부분 기본값 그대로도 무리 없이 돌아가게 하되, 원하는 항목은 자유롭게 바꿀 수 있게 한다.

16. 제작 타임라인 (4개월 기준)
4개월(16주) 기준으로 작성했다. 멀티플레이 복제, 실시간 음성 변조, 텍스트 동시 제출 동기화, 8단계 상태 머신을 포함하는 범위라, 프로그래머 1~2인 + 아티스트 1인 규모의 소규모 팀을 전제로 한 일정이다. 솔로 개발이라면 소음 소품 개수를 줄이거나, 판정단 2인 모드·후보자 투표 옵션 같은 실험적 기능을 4개월 이후로 미루는 등 범위 축소를 권장한다.

"진짜 지정 방식 — 후보자 투표" 옵션의 세부 흐름(누가 언제 투표하는지, 판정단에게 노출되지 않는 절차).
모방자 외형 재조정(모창 준비) 시간의 정확한 길이와 UI — 전신이 잘 보이는 프리뷰 카메라/미러 형태가 필요할지 확정.
로비 커스터마이징 파츠 범위(색상 팔레트·의상 슬롯·액세서리 개수 등)와 사용할 SD 로우폴리 애셋팩 확정.
판정단용 더미 편집 화면의 구체적 연출 — 실제 커스터마이징처럼 보이게 할지, 단순 대기 화면으로 처리할지.
'진짜'의 외형이 스냅샷 이후 완전히 잠기는 것을 본인에게 어떻게 안내할지(로비에서 미리 예고 문구를 줄지, 잠기는 순간 별도 UI로 알릴지).
