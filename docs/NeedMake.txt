JINZZA - 3D Modeling Needed (NeedMake.txt)
Generated 2026-09-16, by Claude Code, verified live against the running editor (every item
below was checked directly - which mesh is actually assigned right now - not guessed from
memory). Everything listed currently renders using an Engine primitive shape (Cube/Cylinder/
Sphere/Cone) or has no mesh at all, standing in for real art. Nothing here blocks gameplay -
it's a pure art backlog.

=================================================================
1. MAIN CHARACTER
=================================================================
- Seal character body: currently a rigid StaticMesh (SM_Seal) glued to the capsule - no skeleton,
  no animation at all (no idle/walk/jump). A previous attempt at a rigged, animated seal
  (SKM_Seal) was abandoned: the rig kept coming out visually broken, and separately, Unreal
  5.4+'s "First Person Rendering" feature silently failed to render a from-scratch custom
  skeleton at all in first-person view. If real animation is wanted, this needs a proper
  sculpted/skinned seal model + a working rig, built with that first-person rendering
  requirement checked from the start (not discovered after the fact).
- Face disguise materials (MI_Face_A / MI_Face_B / MI_Face_C): the 3-way "which face is the
  real one" disguise system has real code wired up (UjinzzaDisguiseComponent) but no material
  assets to actually apply - right now it's a no-op. Needs 3 distinct face looks (paint/material
  variants, not necessarily separate meshes) for the seal.
- Hair accessory: a placeholder sphere (/Engine/BasicShapes/Sphere) tinted by the player's chosen
  hair color. Needs a real hair/headpiece model.
- Accessory item: a placeholder cube (/Engine/BasicShapes/Cube) tinted by the player's chosen
  accessory style. Needs a real accessory model (hat, bandana, etc. - whatever fits a seal).
  Note: both of the above are currently socketed to the OLD Mannequin skeleton, which is hidden
  now that the real body is the static seal mesh - see docs/TODO.md for that unresolved
  architecture question before modeling hair/accessories that need to actually attach to the
  seal's body.

clock face for the wall clock).
